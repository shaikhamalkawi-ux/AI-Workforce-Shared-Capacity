# Data and Code Availability

Public reproducibility repository:

https://github.com/shaikhamalkawi-ux/AI-Workforce-Shared-Capacity

The repository contains the fixed 169-origin System-A denominator, the prespecified 335-edge released/no-backfill baseline, BLS 2024–34 and 2025–35 model-relevant vectors, route-definition and opening-access outputs, origin-side and minimum-cut certificate materials, replay code, integrity manifests, and aggregate longitudinal SIPP uncertainty/concordance outputs with analysis code.

The large DOL/Emsi Career Pathways source is not redistributed. A full route rebuild requires reacquiring the public-use file and matching the SHA-256 recorded in `docs/DATA_ACQUISITION.md`.

Raw SIPP microdata, upstream person-level analytical extracts, and event-level person records are not redistributed. The repository includes aggregate rate, uncertainty, concordance, and receiving-destination support outputs, together with the analysis script and integrity records.

System-B aggregate rules and reported results are documented, but the row-level System-B graphs required for a new longitudinal System-B concordance calculation are not included.
